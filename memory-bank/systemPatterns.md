# System Patterns

## Arquitectura
- **MVC (Model-View-Controller)**: Separación clara entre datos (Python), representación (HTML/CSS) y coordinación (Flask Routes).
- **Client-Side Interaction**: JavaScript manejará las transiciones de preguntas para una sensación de App moderna (SPA-like feel en la parte del quiz).

## Patrones de Código
- Inyección de datos mediante Jinja2 para la carga inicial.
- Endpoints JSON en el backend para actualizaciones de estado si es necesario.
