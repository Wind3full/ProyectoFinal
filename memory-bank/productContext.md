# Product Context

## ¿Por qué existe este proyecto?
Para demostrar el uso de patrones de diseño MVC en aplicaciones web con Flask y crear una experiencia de usuario atractiva para la realización de tests.

## Problemas que resuelve
- Gestión estructurada de preguntas y respuestas.
- Interfaz de usuario intuitiva y moderna.
- Flujo de retroalimentación inmediata para el estudiante/usuario.
